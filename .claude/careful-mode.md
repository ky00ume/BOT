# Careful Mode - 최적화된 지침문 작성 절차

이 파일은 복잡하거나 모호하거나 되돌리기 어려운 작업 시 자동으로 적용된다.
[작업 설명]은 사용자가 보낸 입력 전체를 그대로 사용한다.

---

## 절차

### 1단계 - 의도 파악
사용자 입력에서 핵심 의도와 목표를 파악한다.

### 2단계 - 정보 식별 및 질문
아래 관점에서 판단할 수 없는 정보가 있으면 반드시 질문한다:
- 기술적 전제조건 (언어, 프레임워크, 환경)
- 범위 제약 (포함/제외 범위)
- 품질 기준 (성능, 보안, 접근성 등)

질문이 없는 경우: 그 이유를 한 줄로 명시하고 다음 단계로 진행한다.
답변이 불충분하면 후속 질문을 한다.

### 3단계 - 지침문 작성
질문에 대한 답변을 모두 받은 뒤, 아래 구조로 지침문을 작성한다.
실제 코드, 파일, 결과물은 이 단계에서 생성하지 않는다.

```
- 목표: 이 작업이 달성해야 할 것 (한 문장)
- 맥락: 작업의 배경과 현재 상태
- 필수 조건: 반드시 지켜야 할 것
- 금지 사항: 반드시 피해야 할 행동 (3개 이내, 작업 설명과 질의응답에서 도출된 것만)
- 출력 형식: 결과물의 형태와 상세도
- 검증 기준: 성공 여부를 판단할 수 있는 구체적이고 측정 가능한 조건
```

### 4단계 - 승인 요청
작성한 지침문을 사용자에게 보여주고 수정 여부를 확인한다.

### 5단계 - 실행
사용자가 승인하면 지침문에 따라 작업을 실행한다.
