# Churider sound cue assets

Drop short audio files (`.mp3`, `.ogg`, `.wav`, `.flac`, `.m4a`) into cue folders. The SoundDirector randomly selects a file from the requested cue folder.

Initial cues:
- `life/mining/start`, `life/mining/hit`
- `life/woodcut/start`, `life/woodcut/hit`
- `life/gather/start`, `life/gather/pick`
- `life/gather/complete`, `life/gather/stop`
- `craft/smithing/complete`, `craft/alchemy/complete`
- `craft/cooking/complete`, `craft/general/complete`

For downloaded assets, record the source page in `SOURCES.md` so each file remains traceable.
